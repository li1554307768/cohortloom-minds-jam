# Demo Script

Target length: about 90 to 120 seconds.

---

Hi, this is CohortLoom.

It is a persistent experiment memory for creators.

The app starts with weekly engagement metrics, then helps the creator write one falsifiable audience hypothesis from that data. That hypothesis is always creator-approved before anything else happens.

If the creator approves it, CohortLoom prepares one manual 7-day experiment with explicit success and stop conditions. It does not post, message, or run outreach by itself.

The Minds layer is only for persistence. Live evidence verifies that one Mind stored the approved hypothesis, recalled it for a 7-day plan in a second conversation, and recalled it again for the due review in a third conversation.

The due-review request is intentionally narrow. It does not repeat the hypothesis body. That keeps the loop auditable and reduces the chance of drift.

The hypothesis, metrics, experiment, and result in the demo are still synthetic, and that is on purpose. Live continuity does not mean real users, growth, or revenue. The point is to show a safe workflow for learning from audience signals without turning the product into an inbox, a scheduler, or an autopilot.

So the loop is simple:

weekly metrics -> creator-approved hypothesis -> 7-day manual experiment -> due review.

That is what CohortLoom does.
